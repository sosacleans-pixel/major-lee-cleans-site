# Major Lee Cleans website

Branch `golive`: production-ready static site for https://majorleeclean.com/ (indexable, canonical set, robots.txt, sitemap.xml, 404.html). No analytics.
Branch `main`: internal preview with placeholders and noindex.

Run locally: `python3 -m http.server 8080` then open http://localhost:8080

Quote form is intentionally replaced by an "Email us for a quote" mailto to majorleeclean@gmail.com. A form service (e.g. FormSubmit) can be added after owner approval and a one-time activation click from that inbox.
Hidden until confirmed by the owner: phone, prices, hours, owner story, reviews, insured/bonded, eco-friendly products, supplies and cancellation policies, social links, legal business name.
